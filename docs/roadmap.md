# 后续改进方向

当前功能和限制以 [协议兼容说明](onebot-compatibility.md) 与 [网络配置](network-config.md) 为准。本页列出可继续改进的方向，不作为已实现功能或交付时间的承诺。

## 兼容与可靠性

- 扩展外部 OneBot v11 客户端的端到端兼容测试。
- 增加长时间运行、重连、事件去重和异常退出的覆盖。
- 改善群角色、群名片与成员缓存的映射和诊断。
- 扩展隔离 Windows 环境中的原生桥接与自启验证。

## 能力扩展

撤回动作、合并转发发送和群管理仍受原生接口限制，按不支持处理。入站合并转发及引用的解析、嵌套内容和 `get_forward_msg` 已在当前源码实现，范围见 [富消息与引用](rich-messages.md)。新增能力应同时提供实际桥接实现、明确的协议结果和回归验证。无法完成的操作必须返回显式错误。

账号 WebUI 负责账号、桥接、网络端点与诊断；机器人回复逻辑和业务功能由外部 OneBot 客户端实现。
