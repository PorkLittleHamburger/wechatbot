## 4.2 功能边界

上游对上述 4.2 构建提供账号识别、文本与真实群 @、图片、普通文件和语音收发，以及群成员缓存与系统事件的分项适配；真实验证范围以固定来源的 [原生说明](../vendor/helper/native/README.md) 为准。本项目离线回归不替代实机收件验证。

- 联系人全量扫描、表情包发送在上游 4.2 后端未开放，网关不宣称可用。已观测用户资料及群成员查询仍可复用；缺失资料保持明确未知。
- 入站引用仍走网关的有界富内容解析；图片、链接和嵌套记录保留原有账号隔离及可用性说明。没有缓存或正文的历史引用仍可能不可恢复。
- 上游新增的视频、原生引用发送、朋友圈、公众号和本机防撤回没有在本次新增 OneBot 映射。出站 `reply` 继续明确失败；转发发送仍转换为普通消息。
- 保留守护日志、DLL 完整路径校验、文件/语音路径、快照权限、原生 @ 标签间隔及桥接恢复控制器的本地修复。

## 升级与验收

停止实例后导入完整 v0.9.4 包并切换运行版本，保留配置、账号 SQLite 和媒体目录；不要只替换 DLL。旧配置中的版本列表是显示信息，不覆盖原生指纹检查。Launcher 本体无需因此重新发布，但旧实例必须切换到新 Bot 包。

本轮在 2026-11-11 进行源码回归、原生编译和便携包验证。没有注入当前微信、发送真实消息或替换运行实例；匹配构建上的登录发现、启停、群 @、普通及引用图片仍需升级后实机验收。
